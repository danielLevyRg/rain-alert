# ☔ Rain Alert

בוט שבודק את תחזית הגשם כל 15 דקות, ושולח הודעה בטלגרם בערך שעה לפני שאמור להתחיל לרדת גשם, לפי המיקום שלך.

## איך זה עובד

1. **GitHub Actions** מריץ את `rain.py` כל 15 דקות (חינמי בריפוזיטורי ציבורי).
2. הסקריפט קובע את המיקום:
   - אם שיתפת בצ'אט עם הבוט **Live Location** (ב-12 השעות האחרונות), הוא משתמש בו.
   - אחרת הוא משתמש בקואורדינטות ברירת המחדל שהוגדרו ב-Secrets.
3. הסקריפט מושך תחזית ברזולוציה של 15 דקות מ-[Open-Meteo](https://open-meteo.com) (חינמי, ללא מפתח API).
4. אם צפוי גשם ב-75 הדקות הקרובות, והוא עוד לא יורד, נשלחת הודעה בטלגרם.
5. כדי לא להציף בהודעות, הסקריפט שומר ב-`state.json` את זמן תחילת הגשם האחרון שהתריע עליו, ולא מתריע שוב על אותו גשם.

## מבנה הפרויקט

```
.
├── rain.py                    # הלוגיקה הראשית
├── state.json                 # נוצר אוטומטית, מונע התראות כפולות

```

## הגדרה

### 1. בוט בטלגרם

1. ב-Telegram פתח צ'אט עם **@BotFather** ושלח `/newbot`.
2. שמור את הטוקן שהוא נותן.
3. שלח לבוט החדש הודעה כלשהי.
4. פתח בדפדפן `https://api.telegram.org/bot<TOKEN>/getUpdates` ומצא את `"chat":{"id":...}`. זה ה-Chat ID.

### 2. Secrets ב-GitHub

ב-**Settings → Secrets and variables → Actions** הוסף:

| שם | ערך |
|---|---|
| `TELEGRAM_TOKEN` | הטוקן מ-BotFather |
| `TELEGRAM_CHAT_ID` | ה-Chat ID שלך |
| `DEFAULT_LAT` | קו רוחב של מיקום ברירת המחדל |
| `DEFAULT_LON` | קו אורך של מיקום ברירת המחדל |

> ⚠️ הריפוזיטורי ציבורי, לכן לעולם לא לכתוב טוקנים או קואורדינטות בקוד עצמו, רק ב-Secrets.

### 3. בדיקה

ב-**Actions → Rain alert → Run workflow** הגדר `test` ל-`yes`. אמורה להגיע לטלגרם הודעה "בדיקה: הבוט עובד ✅" עם מקור המיקום (`default` או `live`).

## מיקום חי

בצ'אט עם הבוט: 📎 ← **Location** ← **Share My Live Location**, ובחירת משך זמן. כל עוד השיתוף פעיל הבוט עוקב אחריך.

## כוונון

הקבועים בראש `rain.py`:

| קבוע | ברירת מחדל | משמעות |
|---|---|---|
| `RAIN_MM` | `0.2` | כמות גשם (מ"מ ב-15 דקות) שנחשבת "גשם". להקטין אם מפספסים גשם, להגדיל אם יש התראות שווא |
| `LOOKAHEAD_MIN` | `75` | כמה דקות קדימה מסתכלים |

כדי לבדוק התראה אמיתית בלי לחכות לגשם, אפשר זמנית להגדיר `RAIN_MM = 0.0` ו-`LOOKAHEAD_MIN = 1440`, ולהחזיר אחר כך.

## מגבלות ידועות

- הרצות מתוזמנות ב-GitHub Actions לא מדויקות לדקה ולפעמים מתעכבות.
- GitHub עלול להשבית הרצות מתוזמנות בריפוזיטורי ללא פעילות כ-60 יום. במקרה כזה מפעילים מחדש בלשונית Actions.
- דיוק התחזית ברמת הדקות משתנה לפי אזור.

## רעיונות להמשך

- ניסוח ההודעה באמצעות LLM (למשל "קח מעיל, הגשם מתחיל ב-17:20 וימשך שעתיים").
- הצגת עוצמת הגשם והסתברות לגשם בהודעה.
- פקודות בבוט, כמו "מה התחזית למחר".
- עדכון מיקום אוטומטי מהטלפון (Shortcuts באייפון, Tasker באנדרואיד).
